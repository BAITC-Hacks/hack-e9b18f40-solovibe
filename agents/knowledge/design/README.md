# Product visual direction

Use SYSTEM.md for palette, typography, material and component behavior; DIRECTION.md for original dimensional art direction; UX.md for understandable flows; MOTION.md for interaction feedback; COPY.md for authored language. Build product components from these specifications and the actual case.

The planner proposes an original identity with the concept: two-word PascalCase name, short Russian slogan, one-sentence product description and a logo direction. Show a small original sketch or SVG proposal to assess the mark, including silhouette, meaning, wordmark relationship, monochrome use and readability at small sizes. This proposal is part of concept approval, not permission to implement product screens before approval.

Compose the landing around a real result, meaningful transformation and clear first action. Create original scenes and layout for the product. Use consistent porcelain, ink and teal materials, but do not treat a palette as sufficient visual design. Working surfaces prioritize readable content, understandable hierarchy and fast interaction. Three-dimensional art can make the identity memorable when it expresses the product's purpose; DIRECTION.md explains construction.

Establish shared tokens and accessible primitives before parallel UI work. Choose only components required by actual user tasks. Preserve complete ru/kk/en behavior, responsive layouts and useful error states throughout.
